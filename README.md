## Overleaf

Keep the root `main.tex` selected as the Main document. It is a small entry point that imports `hw1/hw1.tex`; edit the actual homework inside `hw1/`. This follows [Overleaf's documented proxy-main pattern](https://docs.overleaf.com/getting-started/recompiling-your-project/the-main-document).

Pull the latest GitHub changes in **Integrations > GitHub**, then recompile. GitHub synchronization is manual.
